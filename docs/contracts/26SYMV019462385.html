τεχνολογίες, προκειμένου να γίνει ο χωρικός προσδιορισμός, να είναι γνωστή η ακριβής

και να καταστεί δυνατή η διαίρεσή τους σε λιβαδικές μονάδες, οι οποίες θα
κατανεμηθούν στη συνέχεια στους κτηνοτρόφους, ούτως ώστε να εξατομικευτεί η χρήση
τους.
