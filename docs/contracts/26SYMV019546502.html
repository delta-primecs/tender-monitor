Η πληρωμή των παρεχόμενων υπηρεσιών της σύμβασης θα γίνεται τμηματικά (κάθε δύο μήνες)

Τα μέρη θα προσπαθούν να επιλύουν οποιαδήποτε διαφορά τους που θα προκύψει από την
