(Γενικός Κανονισμός για την Προστασία Δεδομένων), των προσωπικών δεδοµένων µου, τα οποία
δηλώνονται στη σχετική σύμβαση μίσθωσης υπηρεσίας στο οποίο συμμετέχω, για τους σκοπούς

ασφαλιστικούς, καταβολής αμοιβών και για κάθε σκοπό που συνιστά εκτου νόµου υποχρέωση της ΖζΕΥΞΙΣ
ΜΚΟ. Αποδέκτης των ανωτέρω προσωπικών δεδοµένων θα είναι η ΖΕΥΞΙΣ ΜΚΟ, το οποίο και θα τα

επεξεργάζεται για τους ανωτέρω περιγραφόµενους σκοπούς.

2.Επίσης, δηλώνω ότι ενηµερώθηκα τι έχω δικαίωµα πρόσβασης και διαγραφής, για τα προσωπικά
δεδοµένα, που µε αφορούν, καιτα οποία αποτελούν αντικείµενο επεξεργασίας, καθώς και ότι μπορώ να

ανακαλέσω ελεύθερα και αζηµίως την παρούσα δήλωση συναίνεσης.

3.Σχετικό αίτηµά µου θα πρέπει να απευθύνεται εγγράφως προς την ΖΕΥΞΙΣ ΜΚΟ. Η ΖΕΥΞΙΣ ΜΚΟ έχει
δικαίωµα να αρνηθεί το αίτηµα διαγραφής αν η τήρηση των δεδοµένων εἶναι απαραίτητη για τη
θεμελίωση, άσκηση ή υποστήριξη νόµιµων δικαιωμάτων του, καθώς για τις ανάγκες τήρησης της
Φορολογικής, ασφαλιστικής ή εν γένει εργατικής νομοθεσίας. Τέλος, αναλαμβάνω την υποχρέωση να

ενημερώνω έγκαιρα τη ΖΕΥΞΙΣ ΜΚΟ για τυχόν µεταβολή των παραπάνω προσωπικών δεδοµένων µου.
